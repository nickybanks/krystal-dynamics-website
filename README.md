# Krystal Dynamics – Official Website Repository

This repository hosts the official website and supporting infrastructure for **Krystal Dynamics** audio software.

Krystal Dynamics is an independent audio software project focused on clean, precise and professional tools for modern mixing and mastering workflows.

---

## Purpose of This Repository

This repository is dedicated to:

- Hosting the official website (GitHub Pages)
- Maintaining update metadata for plugin notifications
- Archiving legacy distribution files

Plugin binaries can be downloaded from itch.io through the official website and are also maintained in their respective dedicated repositories.

---

## Current Products

Krystal Dynamics currently develops the following free audio plugins:

- **KrystalComp** – Transparent digital compressor with Peak/RMS detection and sidechain EQ  
- **KrystalClip** – Digital clipper with selectable clipping modes and slope control  
- **KrystalField** – Single-band dynamics processor combining upward and downward compression
- **KrystalPeak** – Transparent digital peak limiter with adjustable attack and release times
- **KrystalShaper** – Advanced transient processor with different modes and controls 

All plugins are free for personal and commercial music production.

### How downloads work

Downloads from the official website are handled through **[itch.io](https://krystal-dynamics.itch.io/)**, which uses a **"pay what you want"** model: you can download any plugin for free, or optionally choose to pay an amount of your choice to support the project. The price never affects what you get: every download is the full, unrestricted plugin. You can also support the project through the official **[Patreon](https://www.patreon.com/c/Krystal_Dynamics)**

Plugins can be downloaded from:
- The [official website](krystaldynamics.com) (each plugin page links to its itch.io download page)
- [itch.io](https://krystal-dynamics.itch.io/) (pay what you want)
- [MuseHub](https://www.musehub.com/partner/krystal-dynamics)
- The dedicated GitHub repositories of each product

## Repository Structure

- `versions/` – JSON files used for in-plugin update notifications  

---

## Update Notification System

The `versions/` directory contains JSON metadata used by plugins to notify users when a new version is available.

`assets/data/plugins.json` is the single source of truth: add a release at the top of a plugin's `history` (date as `YYYY-MM-DD`) and push. The files in `versions/` are generated by `tools/build_versions.py`, which runs automatically on every deploy (step `Build version files` of the `Deploy static content to Pages` workflow). It can also be run manually with `python3 tools/build_versions.py` to preview the output.

- `<plugin>_version.json` – legacy schema read by already released plugins (latest release only)
- `<plugin>_changelog.json` – full release list, read by plugins with the new update notifier
- extra names listed in a plugin's `versionFileAliases` (e.g. `KrystalPeak_version.json`) – same content as `<plugin>_version.json`, for plugins that request a different file name

Aliases that differ only in upper/lower case cannot coexist on a Mac disk: they are created by the deploy workflow on Linux, so they do not need to be committed.

Do not edit `versions/` by hand.

This system:
- Does not collect user data  
- Does not perform automatic downloads  
- Only checks version numbers to display update notifications
