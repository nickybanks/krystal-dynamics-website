# Krystal Dynamics – Official Website Repository

This repository hosts the official website and supporting infrastructure for **Krystal Dynamics** audio software.

Krystal Dynamics is an independent audio software project focused on clean, precise and professional tools for modern mixing and mastering workflows.

---

## Purpose of This Repository

This repository is dedicated to:

- Hosting the official website (GitHub Pages)
- Managing visual assets and branding materials
- Maintaining update metadata for plugin notifications
- Archiving legacy distribution files

Plugin binaries are maintained in their respective dedicated repositories.

---

## Current Products

Krystal Dynamics currently develops the following free audio plugins:

- **KrystalComp** – Transparent digital compressor with Peak/RMS detection and sidechain EQ  
- **KrystalClip** – Digital clipper with selectable clipping modes and slope control  
- **KrystalField** – Single-band dynamics processor combining upward and downward compression  

All plugins are free for personal and commercial music production.

For downloads, please refer to:
- The official website
- MuseHub
- The dedicated GitHub repositories of each product

---

## Repository Structure

- `index.html` – Main website entry point  
- `plugins/` – Individual plugin pages  
- `assets/` – Images, logos, and brand materials  
- `versions/` – JSON files used for in-plugin update notifications  

---

## Update Notification System

The `versions/` directory contains JSON metadata used by plugins to notify users when a new version is available.

This system:
- Does not collect user data  
- Does not perform automatic downloads  
- Only checks version numbers to display update notifications
