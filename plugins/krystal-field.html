KrystalField

KrystalField is a mastering-grade dynamic processor featuring dual compression engines for simultaneous downward and upward compression. This approach provides precise control over mix dynamics, making it suitable for mastering, bus processing, and final mix polish.

Download

Windows (VST3) macOS (AU/VST3)

Completely FREE for personal and commercial use

Features

  • Dual dynamic processors for downward and upward compression
  • Target-based threshold controls
  • Unified attack and release controls
  • Independent ratio and knee controls
  • RMS, Peak, and LOUD detection modes
  • Auto makeup gain
  • Mix control for parallel processing
  • Lookahead delay up to 20ms
  • Low frequency bias for sidechain filtering
  • Hard and soft clipping modes
  • Bypass for A/B comparison
  • Gain reduction and short-term LUFS metering
  • Real-time waveform display

Installation

Windows

VST3
Recommended
  1. Download the .zip package and extract it.
  2. Run KrystalField-Windows-installer.exe and follow the on-screen instructions.
  3. Restart your DAW and rescan plugins if needed.
Manual installation (if the installer can't be used)
  1. Copy KrystalField.vst3 to C:\Program Files\Common Files\VST3.
  2. Restart your DAW and rescan plugins if needed.

Note: Some systems may show a security warning for unsigned installers. If this happens, use the manual method.

macOS

AU / VST3
Recommended
  1. Download the .zip package and extract it.
  2. Open KrystalField-MacOS-installer.pkg and follow the on-screen instructions.
  3. Restart your DAW and rescan plugins if needed.
Manual installation (if the installer can't be used)
  1. Copy KrystalField.component (AU) to /Library/Audio/Plug-Ins/Components.
  2. Copy KrystalField.vst3 (VST3) to /Library/Audio/Plug-Ins/VST3.
  3. Restart your DAW and rescan plugins if needed.

Note: If macOS blocks the installer, you may need to allow it in System Settings > Privacy & Security. Apple guidance is available here.
