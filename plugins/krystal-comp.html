Overview

KrystalComp is a precision digital compressor designed for mixing and mastering workflows. It combines surgical control over dynamics with flexible sidechain processing, offering both RMS and Peak detection modes for accurate compression tailored to your source material.

Features

  • Standard compression controls: Threshold, Ratio, Attack, Release
  • Variable knee control for compression curve shaping
  • RMS and Peak detection modes
  • Input and makeup gain controls
  • Mix control for parallel processing
  • Internal and external sidechain input
  • Sidechain signal equalizer with LP, HP, and bell filters
  • Monitor button for sidechain signal audition
  • Comprehensive input, output, and gain reduction metering
