KrystalClip

KrystalClip is a clipping processor featuring three distinct saturation algorithms for controlled peak limiting. Each mode provides different harmonic characteristics, from transparent loudness control to creative saturation, making it suitable for mixing, mastering, and sound design applications.

Download

Windows (VST3) macOS (AU/VST3)

Completely FREE for personal and commercial use

Features

  • Three clipping modes with different harmonic colorations
  • Threshold control for clipping point adjustment
  • Slope control to shape the clipping curve
  • Input and output gain controls
  • Mix control for parallel processing
  • Oversampling up to 8x
  • Bypass for A/B comparison
  • Delta mode for precise clipping control
  • Automatic loudness matching with informative feedback
  • Real-time waveform display with short-term LUFS metering
  • Comprehensive input and output metering

Installation

Windows

VST3
Recommended
  1. Download the .zip package and extract it.
  2. Run KrystalClip-Windows-installer.exe and follow the on-screen instructions.
  3. Restart your DAW and rescan plugins if needed.
Manual installation (if the installer can't be used)
  1. Copy KrystalClip.vst3 to C:\Program Files\Common Files\VST3.
  2. Restart your DAW and rescan plugins if needed.

Note: Some systems may show a security warning for unsigned installers. If this happens, use the manual method.

macOS

AU / VST3
Recommended
  1. Download the .zip package and extract it.
  2. Open KrystalClip-MacOS-installer.pkg and follow the on-screen instructions.
  3. Restart your DAW and rescan plugins if needed.
Manual installation (if the installer can't be used)
  1. Copy KrystalClip.component (AU) to /Library/Audio/Plug-Ins/Components.
  2. Copy KrystalClip.vst3 (VST3) to /Library/Audio/Plug-Ins/VST3.
  3. Restart your DAW and rescan plugins if needed.

Note: If macOS blocks the installer, you may need to allow it in System Settings > Privacy & Security. Apple guidance is available here.
